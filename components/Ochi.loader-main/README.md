# ✨ Animated Loader

A smooth, modern **animated loader** inspired by **award-winning websites**, built using **HTML, CSS, and JavaScript**.  
This project focuses on **motion design, timing, and visual polish** to create a premium loading experience.

## 🧠 Inspiration

This loader is inspired by **live, award-winning websites** known for their:
- High-quality animations
- Smooth transitions
- Minimal yet impactful motion design

The goal was to **study, recreate, and understand** how professional web animations are built and timed.

---

## 🚀 Features

- 🎬 Smooth entrance & exit animation
- ⚡ Lightweight and fast
- 🎨 Clean and modern design
- 📱 Fully responsive
- 🧩 Easy to integrate into any website

---

## 🛠️ Built With

- **HTML5** – structure  
- **CSS3** – animations & transitions  
- **JavaScript** – timing & control  

No libraries. No frameworks.  
Just **pure frontend fundamentals**.
